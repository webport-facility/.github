### 🍴 Forking & Contributing
We welcome community contributions, bug reports, and optimizations. If you are interested in helping improve our webports, please follow these steps:

1. **Fork the Repository:** Click the "Fork" button at the top right of the repository page to create your own copy.
2. **Clone Locally:** Clone your fork to your local machine using `git clone https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git`.
3. **Create a Branch:** Create a new branch for your changes (`git checkout -b feature/your-feature-name`).
4. **Make Changes & Commit:** Ensure your code is clean, tested, and follows the existing project structure. Commit your changes with clear messages.
5. **Push & Open a PR:** Push your branch to your fork on GitHub and open a Pull Request against our `main` branch. Provide a detailed description of what you changed and why.

*Note: By contributing, you agree that your contributions will be licensed under the same AGPL license as the project.*

### ⚖️ License Information
All repositories under the Webport Facility are licensed under the **GNU Affero General Public License v3.0 (AGPLv3)**, unless otherwise stated. 

**Why AGPL?**
Because our projects run as webports—software accessed over a network rather than just downloaded locally—the AGPLv3 ensures that the source code remains free and open. The key difference between the standard GPL and the AGPL is the *Network Use Clause*:

- **Network Interaction:** If you modify our webports and make them available over a network (such as hosting the ported game on your own website), the AGPL requires you to make the complete corresponding source code of your modified version available to the users interacting with it over that network.
- **Copyleft:** Any derivative work must also be licensed under the AGPLv3, ensuring the software remains free and open for the community.

You can read the full legal text of the license in the `LICENSE` file included in every repository, or read the official summary on the [GNU website](https://www.gnu.org/licenses/agpl-3.0.html).
